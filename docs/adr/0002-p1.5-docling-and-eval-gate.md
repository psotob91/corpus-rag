# 2. P1.5 docling route + the eval gate for P2/P3

Date: 2026-06

## Status

Accepted. Supplements ADR-0001.

## Context

P1 shipped a lean PyMuPDF ingester whose heading nesting was a font-size
heuristic (it mis-nested a real PLOS paper's sections under "Abstract") and whose
formula LaTeX was always empty. ADR-0001 also deferred the hybrid-vs-graph
decision to a metrics gate that did not yet exist.

## Decision

1. **P1.5 — docling structural route, default when installed.** Add
   `corpus_rag/ingest/docling_pipeline.py` (optional `--extra docling`; pulls
   torch + layout/TableFormer/CodeFormula models). It produces the **same
   `Intermediate`** shape as the lean route, so `write_product` is reused
   unchanged. `ingest(pdf, engine="auto")` picks docling if importable, else the
   lean PyMuPDF route; override with `CORPUS_RAG_INGEST_ENGINE=pymupdf|docling`.
   The lean route stays as a no-GPU fallback.
2. **eval gate — BenchmarkQED-lite (`corpus_rag/eval/benchmark.py`).** Generate
   LOCAL (single-source) vs GLOBAL (cross-cutting, multi-source) probes from the
   indexed corpus, run the hybrid retriever, and map the local-vs-global recall
   GAP to an explicit thresholded decision. Thresholds live in `rag.config.yaml`.
   **P2 (routing) / P3 (graph) are built only when this gate says so** — not by
   default.

## Evidence (verified on this machine)

- docling on the real PLOS paper (`10.1371/journal.pone.0173955`): 23 sections
  with **real heading titles** (Purpose, Methods, Results, Introduction,
  Patients, Preoperative CRT, ...), 5 tables, 16 figures — a clear structural
  improvement over the lean route. (This clinical paper has 0 display equations,
  so formula->LaTeX is wired but not exercised here.)
- eval on the current corpus (sample + that paper): local recall@10 = 0.97,
  global recall@10 = 0.88 (>= 0.70 threshold) -> **HYBRID_SUFFICIENT**. No graph
  is justified yet. Re-run on the real, larger corpus before deciding P2/P3.

## Consequences

- Default ingestion is now heavier (docling/torch) but higher quality; the lean
  route remains for no-GPU / fast runs via the env override.
- The hybrid-vs-graph decision is now **data-driven and cheap** (LLM-free), run
  before paying to build any graph. Probes are templated, so the local-vs-global
  *gap* is the signal, not absolute scores; regenerate from real user questions
  for a budget decision.
- Deep heading nesting depends on docling emitting distinct header levels (the
  PLOS paper used flat level-1 headers, so paths are flat but correct); the
  nesting logic itself is level-driven (tested).
